One line of earned pride: a grandfather, three winters relearning to walk, carries his granddaughter across an icy yard himself — and she doesn't know to be impressed. A quiet, earned moment of pride for someone in a scene, written in a single line of 146 characters.

The program is deterministic: it always writes the same line to `/output/entry.txt`, well inside the gate's 1–240 character limit, with no setup the reader has to assemble — the pride arrives by the last word.
